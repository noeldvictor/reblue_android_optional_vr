`NativeFogDefinition`/`NativeFogLayers` contain only named semantic values.
`PrepareNativeFog` performs checked source reads and creates at most16 temporary
compatibility writes, with64 bounded control dependencies and no allocation.
Missing/misaligned/overflowing data, nonfinite values, singular active ranges,
control/source aliases and overlapping destinations are refused before mutation.
The source boundary still knows descriptors; native packet/pass consumers do not.

An inactive source byte means **preserve the last publication**, not disable fog
or import unannounced authored changes. Unknown inactive state remains unknown.
Mode0 publishes a disabled native layer with canonical unused values. Active
layers preserve radial/planar and blend/add/subtract modes, including descending
endpoints. Original float and boolean staging words remain exact.

`bd_native_lighting=true` replaces the supported `sub_82179270` body. The original
executes only for explicit fallback or once for comparison when
`bd_native_materials_verify=true`. Initialization, authored changes and the
float/boolean staging/flush adapters remain tracked dependencies.

Each object scope copies both owned layers after pass publication. Both must be
fresh in the current frame. A monotonically advancing publication revision
invalidates older active scopes after late/nested changes, fallback or reinitialization.
Native packet lookup uses the existing exact pose/model ownership; the diagnostic
draw adapter also checks exact context/visual and excludes retained-list draws.
Returned packets own copies after their scope retires. No source memory or
register readback is required to retrieve their fog.

Diagnostic comparison checks the actual normal-lit pixel shader's fog modes and
all active semantic lanes, only when its overall fog-enable flag is set. It reads
the existing CPU constant snapshot and captured booleans, never mapped upload
memory. Bounded candidate logs also expose the selected asset's owned endpoints.
